# Index

### Your thoughts, without the tabs multiplying.

Catch a passing idea, tidy up a to-do list, or keep the good bits from a brainstorm. Index gives your notes a calm little home—and keeps everything right in your browser. No account, server, or build step required. Optional Google Fonts load only when selected; notes fall back to local fonts while offline.

## A few handy things

- **Catch it fast:** jot a quick note and leave the field to save. The first line becomes an optional title.
- **Make it yours:** pin the keepers and undo accidental deletes.
- **Find it again:** search matches note titles and text—even when your spelling is a little adventurous.
- **Choose your view:** switch between list and grid, with card sizes that subtly reflect each note's content.
- **Make each note yours:** open Note appearance from the navigation to choose from 23 Google Fonts and 32 color themes, from soft paper shades to acid brights and dark neon palettes. Settings are saved with that note and apply to its card and editor, with a live preview at the top of the settings.
- **Write your way:** format notes live with `# heading`, `**bold**`, `*italic*`, `__underline__`, `~~strikethrough~~`, `==highlight==`, `> subtext`, `- unordered items`, `1. ordered items`, `[] unchecked tasks`, `[x] completed tasks`, `:left: left-aligned lines`, `:right: right-aligned lines`, and `[link text](https://example.com)`. Unordered markers display as bullets; list prefixes continue when you press Enter, and checkboxes display as Unicode boxes and can be toggled by clicking them or pressing Space when focused. Older `- [ ]` checkbox markers are still recognized. Use the editor toolbar or right-click selected text for formatting and Copy. The first line is the title, and formatting markers stay visible but subtle while you edit.
- **Reorder in a snap:** hold and drag a note on touchscreens, or drag its handle with a mouse.
- **Keep it close:** notes are saved in this browser on this device.

On mobile, the writing tools float within easy thumb reach. On desktop, the notes list fills the window and opening a note brings up a full-screen editor.

## Run it

Open `index.html` in a modern browser for basic use. To install Index and use it offline, serve the folder from `localhost` or an HTTPS host; service workers are not available when opening the file directly. For local testing, run `python -m http.server 8000` in the project folder and open `http://localhost:8000`, then use the browser's Install app or Add to Home Screen command. Selected Google Fonts need an internet connection; system fonts are used otherwise.

## Keyboard shortcuts

- `Ctrl+N` / `⌘N` — make a note.
- `Ctrl+K` / `⌘K` — jump to search.
- `Escape` — head back to the notes list while editing.

Already used Daymark? Index brings those notes along and saves new changes under its own storage key.
