# Index

### Your thoughts, without the tabs multiplying.

Catch a passing idea, tidy up a to-do list, or keep the good bits from a brainstorm. Index gives your notes a calm little home—and keeps everything right in your browser. No account, server, build step, or external dependencies required.

## A few handy things

- **Catch it fast:** jot a quick note and leave the field to save. The first line becomes an optional title.
- **Make it yours:** pin the keepers and undo accidental deletes.
- **Find it again:** search matches note titles and text—even when your spelling is a little adventurous.
- **Choose your view:** switch between list and grid, with card sizes that subtly reflect each note's content.
- **Write your way:** format Markdown as you type in one WYSIWYG-style editor; headings, bold, italics, links, lists, checkboxes, code, and highlights render in place while syntax markers remain subtly visible.
- **Reorder in a snap:** hold and drag a note on touchscreens, or drag its handle with a mouse.
- **Keep it close:** notes are saved in this browser on this device.

On mobile, the writing tools float within easy thumb reach. On desktop, Index keeps your notes and editor side by side.

## Run it

Open `index.html` in a modern browser for basic use. To install Index and use it offline, serve the folder from `localhost` or an HTTPS host; service workers are not available when opening the file directly. For local testing, run `python -m http.server 8000` in the project folder and open `http://localhost:8000`, then use the browser's Install app or Add to Home Screen command. No build step or app dependencies are needed.

## Keyboard shortcuts

- `Ctrl+N` / `⌘N` — make a note.
- `Ctrl+K` / `⌘K` — jump to search.
- `Escape` — head back to the notes list on mobile.

Already used Daymark? Index brings those notes along and saves new changes under its own storage key.
